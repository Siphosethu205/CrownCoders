# AquaCom

## 📖 Overview
AquaCom is a community-driven Android application designed to improve rural water security. It bridges the communication gap between community members, water tanker drivers, and administrators. By providing real-time updates on water availability, emergency request tracking, and tanker location monitoring, AquaCom ensures that water distribution is driven by actual demand rather than fixed, inefficient schedules.

## ✨ Key Features

### 👥 Community Member Features
* **User Dashboard:** View real-time water status updates for your local area.
* **Emergency Water Requests:** Send high-priority alerts for critical water shortages directly to administrators and drivers.
* **Live Tanker Tracking:** Track the real-time location of assigned water tankers, view ETAs, and monitor vehicle distance.
* **Secure Delivery Verification (OTP):** When a tanker arrives, confirm delivery securely using a 6-digit OTP provided by the driver.
* **Water Saving Tips:** Receive dynamic tips to promote water conservation.
* **Feedback System:** Confirm water received or report delivery problems for admin intervention.

### 🛡️ Admin Features
* **Admin Dashboard:** Comprehensive overview of total water reports, available water, active tankers, and pending emergencies.
* **Hotspot Tracking:** Instantly identify locations with the highest number of water shortage alerts.
* **User & Driver Management:** Manage community members, drivers, and water tanker fleets.
* **Analytics & Reporting:** Track usage statistics and generate reports.
* **Broadcast Notifications:** Send alerts and announcements to the entire community.
* **Audit Logs:** Maintain a transparent record of system changes and actions.

## 🛠️ Tech Stack
* **Platform:** Android
* **Language:** Java
* **Backend/Database:** Firebase (Authentication, Realtime Database, Cloud Notifications)
* **UI:** XML Layouts, Material Design Components
